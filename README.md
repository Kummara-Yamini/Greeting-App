# Greeting App

## Description
Greeting App is a simple web application that greets users by their name. Users can enter their name and click the "Greet Me" button to receive a personalized greeting.

## Purpose
The purpose of this project is to practice basic HTML, CSS, and JavaScript concepts, including user input, button click events, and DOM manipulation.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Enter your name.
- Display a personalized greeting.
- Show a message if the name field is empty.
- Simple and attractive user interface.
- Responsive design.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter your name and click **Greet Me**.
